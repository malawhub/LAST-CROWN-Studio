Project, episode, script, character, scene-planning, reference-image, local prompt-building and offline production-pack export tools are available. No credit-based AI generation, narration, editing or video rendering is connected.

Story development workspace

Select a project, write its episode script and keep a reusable character bible. Changes are saved locally in this browser.

Episode manager

Create and switch between episodes. Each episode keeps its own script and scenes.

Character bible

Choose a project to manage its characters.

Scene & shot planner

Break the selected episode into production-ready scenes. Character names are linked to the project's Character Bible.

Saved scene list

Choose a project to plan scenes.

Offline production pack

Export your saved character continuity sheets and scene prompts together as one text file. This is generated on your device and uses no AI service or credits.

Comic & storyboard creator

Arrange images already saved in your Asset Library into ordered comic panels. Add speech, narration or captions, then export a self-contained HTML comic that can be opened offline and printed to PDF. No AI generation or credits are used.

Choose a project to create a comic.

Asset library

Organise character references, scene images and other visual assets by project. Images stay in this browser until you export a backup.

Limit: 800 KB per image and approximately 3 MB total. Use compressed JPG or WebP. Images are stored on this device, not uploaded to cloud storage.

Choose a project to view its assets.
