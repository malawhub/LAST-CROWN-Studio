Episode timeline

Arrange existing scenes, reference images, audio clips and subtitle cues on one episode timeline. This is a local planning editor, not a video renderer. Audio duration is left unset until you enter it.

Choose a project and episode to build its timeline.

Video export (browser-native)

Render the current episode timeline into a video using this browser's canvas and MediaRecorder. Adjacent visual segments crossfade over 0.6 seconds. Each audio timeline item supports volume, stereo pan and fade-in/fade-out controls; subtitle cues are included. The export is local and uses no AI credits. Most browsers produce WebM; MP4 is available only if the browser explicitly supports it. This remains a lightweight storyboard renderer, not a full video editor.

Add visual scenes/images to the timeline and set their durations before rendering.

Audio mix controls are available on each audio item in the timeline: volume (0–200%), stereo pan, fade-in and fade-out. For MP4 on Android, use the included local Termux FFmpeg converter after exporting WebM.
